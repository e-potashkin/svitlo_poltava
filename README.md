# Svitlo Poltava

Графік відключень світла для **Полтави, черга 3.1**. Компонент читає тільки
офіційну сторінку Полтаваобленерго `poe.pl.ua`, без проксі, без інших областей
і без злиття двох API.

Всередині вже є картка Lovelace. Після встановлення HACS додає її ресурс
автоматично.

## Встановлення

1. HACS → Інтеграції → три крапки → **Користувацькі репозиторії**.
2. Додайте `https://github.com/e-potashkin/svitlo_poltava`, категорія
   **Інтеграція**.
3. Встановіть **Svitlo Poltava** і перезапустіть Home Assistant.
4. Налаштування → Пристрої та служби → **Додати інтеграцію** → Svitlo Poltava.
   Запис один, вибір області чи черги не потрібен.

Після цього на сторінці з'явиться картка `custom:svitlo-poltava-card`.

## Картка

```yaml
type: custom:svitlo-poltava-card
entity: sensor.svitlo_poltava_3_1_electricity
title: Полтава — 3.1
```

Картка показує 48 півгодинних слотів на добу, три стани (`є`, `немає`,
`можливе`), наступне вікно, години без світла і таймлайн на 24 години.
Редактор картки вибирає календар `calendar.svitlo_poltava*` і сенсори цієї
інтеграції.

## Сенсори

Компонент створює пристрій **Svitlo Poltava 3.1** з такими сутностями:

| Сутність | Що показує |
| --- | --- |
| `sensor.svitlo_poltava_3_1_electricity` | `Grid ON` / `Grid OFF` / `Possible` |
| `binary_sensor.svitlo_poltava_3_1_power_present` | світло є / немає |
| `sensor.svitlo_poltava_3_1_next_outage` | наступне планове відключення |
| `sensor.svitlo_poltava_3_1_minutes_to_outage` | хвилин до відключення |
| `sensor.svitlo_poltava_3_1_total_outage_today` | годин без світла сьогодні |
| `calendar.svitlo_poltava_3_1_outage_schedule` | календар вікон |

Точні entity ID залежать від мови інтерфейсу під час створення. Перегляньте їх
у **Налаштування → Пристрої та служби → Svitlo Poltava**.

## Оновлення

Компонент опитує сторінку кожні 120 секунд. Інтервал можна змінити в
**Налаштування → Пристрої та служби → Svitlo Poltava → Налаштувати**.

## Міграція зі `svitlo_live`

1. Видаліть стару інтеграцію **Svitlo.live Schedules** разом із її записом.
2. Встановіть **Svitlo Poltava**.
3. Оновіть шаблони та картки, які читали `sensor.svitlo_*` або
   `calendar.svitlo_*`, на нові entity ID.

Якщо старі ID потрібно зберегти, перейменуйте нові сутності в реєстрі або
оновіть шаблони. Компонент не змінює чужі сутності.

## Залежності

Немає. Використовуються тільки модулі Home Assistant.
